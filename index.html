About the data

All dishes in the repo’s data/recipes-*.json shards are listed. The repo was scraped from saved Instagram posts and is uneven, so every dish has a data badge:

  • From repo ingredients and steps are the repo’s own (lightly cleaned: duplicate steps, hashtag lines and nutrition lines removed).
  • From repo (earlier version) the current repo steps belong to another post, so the steps from the repo’s previous version of the same recipe are shown.
  • Repo + filled in ★ repo ingredients, with missing steps written and marked ★.
  • Rewritten the repo still points at an unrelated placeholder recipe (e.g. many chicken dishes → the same French “Chicken Basquaise”), so a standard recipe for the dish name is shown.
  • Partial in repo the repo has only ingredients or only steps; shown as-is.
  • Check the repo’s steps don’t match its ingredients (likely mixed posts); both are shown, with a warning.
  • Recipe missing the repo has no usable recipe (empty, or linked to a different dish). The listing is kept because the dish is in your collection.

Times and calories come from the repo. Its time_source/calories_source labels show whether the post stated them (“from post”) or the repo estimated them, and estimates are marked est.. When a post listed macros, those are shown as “from post”. Otherwise protein/carbs/fat/fibre, servings, difficulty and the comfy “moods” are rough estimates (est.). Categories were re-checked from dish names (the repo category is shown in each recipe), and cuisines left blank by the repo were inferred from the name (marked “inferred”).
