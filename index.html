About the data

All entries in the repo’s data/recipes-01.json are included. The repo data was scraped from saved posts and is uneven, so each recipe carries a data badge:

  • From repo the repo’s recipe is shown as-is (lightly cleaned).
  • Repo + filled in the repo recipe is kept; missing quantities, ingredients or steps were added and marked ★.
  • Rewritten the repo entry was empty or pointed at an unrelated placeholder recipe (e.g. several chicken dishes all pointed at the same French chicken & chorizo recipe), so a standard recipe matching the dish name is shown. The original repo values are listed in each recipe’s “Repo data” box.

Estimated (marked est.): prep/cook/total times, servings, difficulty, calories and macros (protein, carbs, fat, fibre) per serving, and the comfy “best time to cook” moods. They are rough estimates from the ingredients, not lab values. When the original post stated a calorie or time figure, it is shown separately as “post said”.
